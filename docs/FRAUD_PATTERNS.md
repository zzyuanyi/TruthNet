## 0. 重要提示

**本文档定义的"造假模式"是风险信号组合的抽象归纳，不代表对任何具体公司的造假认定。** 每种模式均列出可能的正当替代解释。模式匹配结果仅作为风险研究参考，不构成监管、审计或法律意义上的造假结论。TruthNet 系统始终坚持「识别异常信号、展示证据链路、区分信号与事实」的原则。

## 1. 模式总览

| 编号 | 模式名称 | 触发规则组合 | 核心逻辑 | 置信度 |
|---|---|---|---|---|
| P1 | 收入虚增型 | R1 + R2 (+ R4) | 应收飙升 + 现金流不支撑 → 收入可能虚构 | 3条→high, 2条→medium |
| P2 | 资金占用型 | R3 + R6 | 存贷双高 + 其他应收款大 → 资金可能被关联方挪用 | 2条+关联方信号→high |
| P3 | 利润调节型 | R5 + R7 | 毛利率/费用率异常 + 依赖非经常性损益 → 利润被人为调节 | 2条→high |
| P4 | 资产虚增型 | R1 + R4 + R2 | 应收+存货同时膨胀 + 现金跟不上 → 资产端系统性虚增 | 3条→high, 2条→medium |
| P5 | 综合粉饰型 | 5 条及以上规则 | 多维度信号叠加 → 系统性、多科目协同造假嫌疑 | ≥5条→high, 3-4条→medium |

## 2. 模式详解

---

### P1 · 收入虚增型

#### 2.1.1 触发规则组合

```
R1（应收–营收背离）+ R2（现金流–利润背离）+ [R4（存货–营收背离）]
```

#### 2.1.2 金融逻辑

这是最常见的财务造假路径。企业的利润表展示出亮眼增长，但资产负债表和现金流量表却讲着不同的故事：

- **R1 揭示收入质量问题**：应收账款的增速远超营业收入增速，说明大量销售是"赊"出去的而非"卖"出去的。健康的增长应当是营收带动应收同步增长，而非应收跑在营收前面。
- **R2 揭示现金流问题**：净利润在增长，但经营活动的现金流入却持续为负或极弱。真实的盈利应当最终转化为现金，长期背离意味着利润可能存在于账面而非银行账户。
- **R4 作为增强信号**：如果存货同时异常增长，说明公司可能在虚增存货以平衡虚增收入对应的成本结转——缺乏存货支撑的虚增收入会在毛利率上暴露，因此造假者往往同步虚增存货。

三条信号叠加时，从"收入→应收→现金"的完整链条上均出现异常，是教科书级的虚增收入模式。

#### 2.1.3 典型公司案例

**康美药业（600518.SH）**

康美药业 2016-2018 年间财务造假 887 亿元，其中虚增货币资金 299 亿、虚增营业收入 275 亿、虚增营业利润 39 亿。从规则视角看：

| 规则 | 康美表现 |
|---|---|
| R1 应收–营收背离 | 应收账款从 2016 年的 25.5 亿增至 2018 年的 63.2 亿（+148%），同期营收从 112 亿增至 171 亿（+53%）。应收增速是营收增速的近 3 倍，gap 远超 50pp 红线 |
| R2 现金流–利润背离 | 2016-2018 年累计净利润约 123 亿，但经营活动现金流累计仅约 18 亿。多期现金流/净利润比 < 0.3 |
| R4 存货–营收背离 | 存货从 52 亿增至 184 亿（+254%），远快于营收增速。存货周转天数从 2016 年的 148 天延长至 2018 年的 383 天 |

**乐视网（300104.SZ）**

乐视网通过复杂的关联交易和版权分销模式虚增收入，2010-2016 年间累计虚增收入约 88 亿。R1（应收暴增）+ R2（经营现金流持续为负）+ R4（存货/版权资产膨胀）三重触发。

#### 2.1.4 置信度

| 条件 | 置信度 | 说明 |
|---|---|---|
| R1 + R2 + R4 同时触发 | **high** | 三条独立信号跨报表交叉印证，误判概率低 |
| R1 + R2 同时触发 | **medium** | 核心逻辑成立，但缺少存货端的增强信号 |
| 仅 R1 或仅 R2 触发 | — | 不构成模式匹配，单规则信号另作评估 |

#### 2.1.5 阶段判断

| 阶段 | 规则表现特征 |
|---|---|
| early_signal | R1 单季触发 yellow，R2/R4 尚未触发 |
| accumulating | R1 + R2 连续两季触发，gap 呈扩大趋势 |
| high_risk | R1 + R2 + R4 同时触发，现金流/利润比持续恶化 |

#### 2.1.6 替代解释

- **行业周期性因素**：某些行业（如建筑、工程）天然存在大额应收账款和较长的现金回收周期
- **客户结构变化**：公司从面向中小客户转向大客户，大客户通常账期更长，导致应收正常增长
- **并购影响**：新并购子公司的应收和存货合并入表可能导致结构性变化，应剔除并购影响后再评估
- **商业模式转型**：从经销转为直销可能同时推高应收和存货，但这是战略选择而非造假

### P2 · 资金占用型

#### 2.2.1 触发规则组合

```
R3（存贷双高）+ R6（其他应收款与关联占用风险）
```

#### 2.2.2 金融逻辑

这是最具中国资本市场特色的造假模式之一。正常的商业逻辑下，企业不会在持有大量现金的同时高息借款——因为多余的现金可以直接偿还借款，降低财务费用。

「存贷双高」本身就已违背商业常识——要么货币资金是假的（被虚构或已被挪用），要么货币资金虽真实但受限（被质押、冻结或用于隐性担保），公司不得不通过借款维持运营资金。

而「其他应收款」是财务造假中著名的"垃圾桶"科目。当这个科目异常膨大时，往往意味着实控人或关联方通过它违规占用上市公司资金。资金流转路径通常是：上市公司通过虚构交易或直接划转将资金转出 → 借记其他应收款 → 资金进入实控人控制的关联方。

R3 + R6 同时触发时，逻辑链完整闭合：**公司账面有大量"现金"却还在借债 + 其他应收款异常增长 → 账上的现金可能已被关联方通过其他应收款转走，公司被迫借债维持运营**。

#### 2.2.3 典型公司案例

**康美药业（600518.SH）**

这是中国资本市场最著名的"存贷双高"案例。2017 年末康美账面货币资金 341.5 亿，占总资产 49.7%；同时有息负债（短期借款 113.7 亿 + 长期借款 39.8 亿 + 应付债券 83.1 亿）合计约 236.6 亿，占总资产 34.4%。

| 指标 | 康美数值 | 阈值 | 判定 |
|---|---|---|---|
| cash_to_assets | 49.7% | 15% | 极度偏高 |
| debt_to_assets | 34.4% | 20% | 偏高 |
| 隐含利率 | ~5.2% | — | 公司在为"不存在的钱"支付真实利息 |
| 其他应收款 | 2017 年 1.85 亿 → 2018 年 92.3 亿（+4890%） | 5000 万 | 极端异常 |

2019 年 4 月，康美公告"会计差错更正"，调减货币资金 299.4 亿元，证实了「货币资金造假 + 资金被关联方占用」的判断。

**康得新（002450.SZ）**

与康美高度相似。2017 年末账面货币资金 185 亿，同时有息负债约 67 亿。2019 年 1 月，康得新 15 亿元超短期融资券违约，而同期账面显示货币资金 150 亿——"有钱却违约"暴露了货币资金的真实状态。证监会调查发现，康得新 2015-2018 年间虚增利润 119 亿元，同时实控人通过关联方非经营性占用资金。

#### 2.2.4 置信度

| 条件 | 置信度 | 说明 |
|---|---|---|
| R3 + R6 同时触发 + Neo4j 图谱存在关联方信号 | **high** | 财务信号 + 关系证据，逻辑链完整 |
| R3 + R6 同时触发，无关联方数据 | **medium** | 财务信号明确，但缺乏关系证据支撑 |
| 仅 R3 或仅 R6 触发 | — | 不构成模式匹配 |

#### 2.2.5 阶段判断

| 阶段 | 规则表现特征 |
|---|---|
| early_signal | R3 触发 yellow/orange（存贷比偏高），R6 未触发 |
| accumulating | R3 + R6 均触发，其他应收款呈上升趋势 |
| high_risk | R3 red + R6 red，隐含利率 > 4%，其他应收款/应收账款 > 1.0 |
| regulatory_action | 已收到交易所问询函或证监局关注函（fcode=5508000000），关注货币资金真实性 |
| confirmed_case | 证监会立案调查（fcode=5507060000 red），最终确认资金占用 |

#### 2.2.6 替代解释

- **行业特性**：房地产企业由于预售制度和项目制运营，可能同时持有大量现金（预收款）和债务（开发贷），但房企的预收款受限、现金有特定用途，与一般企业的存贷双高逻辑不同（本规则已通过 comp_type_code 排除金融企业，Phase C 可进一步排除房企）
- **并购储备**：公司可能为即将进行的大型并购储备现金并同时维持既有债务结构
- **境外资金受限**：境外子公司的资金因外汇管制无法调回境内偿还债务
- **季节性因素**：年末报表时点恰好处于资金流入和债务到期之间的窗口期

### P3 · 利润调节型

#### 2.3.1 触发规则组合

```
R5（毛利率/费用率异常）+ R7（盈利质量与非经常性依赖）
```

#### 2.3.2 金融逻辑

当一家公司同时出现「毛利率/费用率异常偏离自身历史和行业水平」和「盈利高度依赖非经常性损益」时，意味着利润的"质量"和"来源"同时存在疑问：

- **R5 揭示利润表结构异常**：毛利率在短期内大幅提升可能意味着少结转营业成本；费用率大幅下降可能是将本应费用化的支出资本化（如将研发费用转为无形资产）。如果这些变化与行业趋势方向相反，则更加可疑。
- **R7 揭示利润来源不可持续**：净利润增长如果主要来自资产处置、政府补贴、债务豁免等一次性收益，而非主营业务的改善，表明公司可能在用非经常性手段粉饰报表。

两者的组合意味着：**利润表不仅结构在变（毛利率/费用率异常），而且增长引擎也是不可持续的（依赖非经常性）**——公司可能在同时使用多种手段调节利润。

#### 2.3.3 典型公司案例

**獐子岛（002069.SZ）**

獐子岛以"扇贝跑了"闻名，但更值得关注的是其利润调节模式：
- R5 触发：2014 年之前毛利率始终维持在 20-30% 区间，2013 年甚至达到 35%，显著高于同行业水产养殖公司 15% 左右的中位数。2014 年"扇贝绝收"事件后毛利率暴跌至 -5%，反向证明前期毛利率异常偏高系少计成本所致
- 费用率异常：存货（消耗性生物资产）的计量高度依赖主观判断，公司通过调节存货跌价准备来平滑利润

**ST 信威（600485.SH，已退市）**

- R7 触发：2015-2018 年扣非净利润持续为负，但通过海外项目非经常性收益使净利润维持在正值，避免触发退市条件
- R5 触发：在通信行业毛利率普遍下滑至 15-20% 区间的背景下，公司毛利率长期维持在 80% 以上（2015 年 87.6%），显著偏离行业水平
- 2019 年证监会立案调查，认定公司虚增收入、虚增利润

#### 2.3.4 置信度

| 条件 | 置信度 | 说明 |
|---|---|---|
| R5 + R7 同时触发，且 gm_deviation 与行业趋势方向相反 | **high** | 逆行业趋势操作，粉饰动机强烈 |
| R5 + R7 同时触发 | **high** | 利润结构和来源双异常 |
| 仅 R5 或仅 R7 触发 | — | 不构成模式匹配 |

#### 2.3.5 阶段判断

| 阶段 | 规则表现特征 |
|---|---|
| early_signal | R5 或 R7 单条触发 yellow |
| accumulating | R5 + R7 均触发 orange，扣非占净利润比连续下降 |
| high_risk | R5 red（逆行业趋势）+ R7 red（扣非占比 < 0.3），公司存在持续性利润调节需求（如保壳、满足对赌） |

#### 2.3.6 替代解释

- **真实的技术突破或成本优化**：公司可能确实通过技术创新大幅降低了成本，导致毛利率真正提升
- **产品结构升级**：从低毛利产品转向高毛利产品可能带来结构性毛利率提升，这是真实的价值创造
- **资产处置的战略选择**：出售非核心资产变现可能确实是优化资产结构的合理举措，而非保壳手段
- **行业政策变化**：如政府补贴标准调整、税收优惠政策等可能影响非经常性损益的规模

### P4 · 资产虚增型

#### 2.4.1 触发规则组合

```
R1（应收–营收背离）+ R4（存货–营收背离）+ R2（现金流–利润背离）
```

#### 2.4.2 金融逻辑

P4 是 P1（收入虚增型）的升级版本——不仅虚增了收入端的应收，还同步虚增了资产端的存货，形成了一个更完整的造假闭环：

```
虚增收入 → 应收账款 ↑（R1 触发）
    ↓
需要匹配成本 → 少结转成本或虚增存货 → 存货 ↑（R4 触发）
    ↓
虚增的利润没有现金支撑 → 经营现金流弱（R2 触发）
```

这个逻辑链条解释了为什么「存货和应收同时膨胀」是特别危险的信号：**造假者往往低估了虚增收入的附带后果——你需要同时虚增资产来吸收虚增的毛利，否则账面毛利率会异常偏高而暴露。** 因此，应收和存货同步膨胀说明公司可能在资产负债表两端同时进行粉饰。

从现金流量表的角度，这些虚增的资产（应收+存货）占用了大量营运资金，导致经营现金流持续弱于净利润，进一步暴露了盈利缺乏现金支撑的事实。

#### 2.4.3 典型公司案例

**康美药业（600518.SH）**

- R1：应收从 25.5 亿→63.2 亿（+148%），远超营收增速（+53%）
- R4：存货从 52 亿→184 亿（+254%），远超营收增速。存货周转天数从 148 天→383 天
- R2：3 年累计净利润 ~123 亿，经营现金流 ~18 亿，平均现金流/利润比 < 0.2
- 三项同时触发，逻辑链完整闭合

**雏鹰农牧（002477.SZ）**

"猪饿死了"事件的主角，但其财务数据同样呈现典型的资产虚增特征。2015-2018 年间：应收账款的增速持续大幅高于营收增速；存货（消耗性生物资产+库存商品）膨胀速度远快于营收；经营现金流持续为负，与净利润严重背离。2019 年公司退市，证监会认定其虚增利润、虚列资产。

#### 2.4.4 置信度

| 条件 | 置信度 | 说明 |
|---|---|---|
| R1 + R4 + R2 同时触发 | **high** | 三条信号覆盖"收入→存货→现金"全链条 |
| R1 + R4 同时触发 | **medium** | 资产负债表两端同步膨胀，但缺现金流验证 |
| R1 + R2 同时触发 | **medium** | 收入端+现金流异常（即 P1 模式），但缺存货证据 |

#### 2.4.5 阶段判断

| 阶段 | 规则表现特征 |
|---|---|
| early_signal | R1 或 R4 单条触发 yellow，R2 未触发 |
| accumulating | R1 + R4 同时触发 orange，应收和存货增速均 > 30% |
| high_risk | R1 + R4 + R2 同时触发 red，存货周转天数 > 365 天，现金流/利润比 < 0 |

#### 2.4.6 替代解释

- **企业快速扩张期**：高速成长的企业可能在短期内应收和存货同时增长，但应有相应的营收增速和现金回收能力支撑
- **备货性行业**：某些行业（如消费电子、芯片）需要在特定时间大量备货，导致存货阶段性升高；如果下游需求真实存在，则不属于资产虚增
- **并购合并报表影响**：收购新公司会导致应收和存货一次性跳升，需要剔除并购影响后再评估
- **供应链战略调整**：从"以销定产"转向"以备促销"可能带来存货结构性变化

### P5 · 综合粉饰型

#### 2.5.1 触发规则组合

```
5 条及以上规则同时触发（R1-R7 中任意 5 条）
```

#### 2.5.2 金融逻辑

当 5 条或更多反欺诈规则同时触发时，单一维度的解释已经无法覆盖所有异常信号。这意味着公司在财务报表的多个环节——收入、成本、现金流、资产质量、盈利可持续性——均出现了显著的异常模式。

从概率论角度，一家健康公司的财务指标偶尔触警 1-2 条是正常的（行业特性、季节性、一次性事件等）。但如果 5 条以上规则同时触发，独立发生的概率极低，更可能是数据背后存在系统性的、协同的粉饰行为。

#### 2.5.3 典型公司案例

**康美药业（600518.SH）** — 7 条规则中至少 5 条可触发：

| 规则 | 触发情况 |
|---|---|
| R1 应收–营收背离 | red — 应收增速远超营收 |
| R2 现金流–利润背离 | red — 利润高但经营现金流极弱 |
| R3 存贷双高 | red — 货币资金和借款双高 |
| R4 存货–营收背离 | orange — 存货增速远超营收 |
| R6 其他应收款关联占用 | red — 其他应收款 2018 年暴增 48 倍 |
| R5 毛利率/费用率异常 | 当期数据覆盖不足（母公司口径），标记 insufficient_data |
| R7 盈利质量 | 扣非数据需核实，Phase C 补充 |

康美的案例完美诠释了：**当一个公司的造假规模足够大时，几乎所有的反欺诈规则都会被触发——因为造假者不可能同时完美地伪造所有财务科目之间的勾稽关系。**

> **关于部分覆盖的说明**：上述分析中 R5 和 R7 因数据限制（母公司口径字段不足、扣非数据待核实）未能触发，但康美仍满足 R1+R2+R3+R4+R6 = 5 条规则触发，P5 判定为 high。
> 若某只股票因数据缺失导致**可用规则总数不足 5 条**（如仅 4 条规则有数据），则 P5 的触发阈值应等比调整：可用规则全部触发 → high，≥75% 触发 → medium。同时在输出中标记 `partial_coverage: true` 及缺失的规则编号。

#### 2.5.4 置信度

| 条件 | 置信度 | 说明 |
|---|---|---|
| ≥5 条同时触发 | **high** | 独立发生的概率极低，系统性造假嫌疑大 |
| ≥5 条触发但 R5 或 R7 标记 insufficient_data | **high** | 触发数达标，但标记 `partial_coverage: true` 提示规则覆盖不完整 |
| 3-4 条同时触发 | **medium** | 多维度有信号，但尚不构成系统性判断 |
| ≤2 条触发 | — | P1-P4 各自的判断逻辑适用，不升级为 P5 |

#### 2.5.5 阶段判断

| 阶段 | 规则表现特征 |
|---|---|
| early_signal | 2-3 条触发 yellow/orange，分散在不同维度 |
| accumulating | 3-4 条触发，其中至少 1 条 red |
| high_risk | ≥5 条触发，其中至少 2 条 red |

## 4. 阶段模型

来自 V12 §2.2 的六阶段模型，用于标记每种模式下的风险演进：

```text
early_signal      — 早期信号：单项或两项指标轻微偏离，需持续观察
accumulating      — 信号积累：多项指标持续触发，信号方向一致
high_risk         — 高风险期：多条规则同时触发 red，跨报表交叉印证
regulatory_action — 监管介入：已收到问询函/关注函/立案调查等监管行动
confirmed_case    — 已有权威事实确认：证监会/交易所已作出正式认定
unknown           — 数据不足无法评估
```

**当前 Phase C 阶段，TruthNet 仅根据财务规则自动判定 early_signal / accumulating / high_risk 三个阶段。** regulatory_action 和 confirmed_case 需依赖外部权威信息（已由事件时间线模块覆盖），系统不自行判定。

## 5. 与 CrossValidate 节点的衔接

本文档定义为 CrossValidate 节点的输入。当规则计算完成后，CrossValidate 节点读取每条规则的 `severity` 和 `status`，按本文档的模式定义进行组合匹配。

匹配逻辑（伪代码）：

```python
def all_triggered(rule_ids: set[str], results: dict) -> bool:
    """所有指定规则均触发（severity != not_triggered 且 status = applicable）。
    
    若任一规则的 status 为 insufficient_data 或 not_applicable，
    该规则不算入触发，但标记在返回结果的 partial_coverage 中。
    """
    return all(
        results.get(rid, {}).get("severity") not in (None, "not_triggered")
        and results.get(rid, {}).get("status") == "applicable"
        for rid in rule_ids
    )


def count_triggered(results: dict) -> int:
    """统计触发的规则总数（排除 insufficient_data / not_applicable）。"""
    return sum(
        1 for rid, r in results.items()
        if r.get("severity") not in (None, "not_triggered")
        and r.get("status") == "applicable"
    )


def _check_related_parties(company_code: str) -> bool:
    """检查 Neo4j 图谱中是否存在关联方信号。Phase C 默认返回 False。
    
    Phase D 接入：查询 Neo4j 中 ACTS_IN_CONCERT_WITH 边，
    或同一 entity_id 出现在 ≥3 家上市公司股东中。
    """
    # Phase C: 图谱已构建但关联方信号判定规则待定义
    return False


def match_patterns(rule_results: dict) -> list[PatternMatch]:
    matches = []

    # P1: 收入虚增型
    if all_triggered({"R1", "R2"}, rule_results):
        confidence = "high" if all_triggered({"R4"}, rule_results) else "medium"
        matches.append(PatternMatch(id="P1", confidence=confidence, ...))

    # P2: 资金占用型
    if all_triggered({"R3", "R6"}, rule_results):
        has_related = _check_related_parties(rule_results.get("company_code", ""))
        confidence = "high" if has_related else "medium"
        matches.append(PatternMatch(id="P2", confidence=confidence, ...))

    # P3: 利润调节型
    if all_triggered({"R5", "R7"}, rule_results):
        matches.append(PatternMatch(id="P3", confidence="high", ...))

    # P4: 资产虚增型
    if all_triggered({"R1", "R4"}, rule_results):
        confidence = "high" if all_triggered({"R2"}, rule_results) else "medium"
        matches.append(PatternMatch(id="P4", confidence=confidence, ...))

    # P5: 综合粉饰型
    triggered_count = count_triggered(rule_results)
    if triggered_count >= 5:
        matches.append(PatternMatch(id="P5", confidence="high", ...))
    elif triggered_count >= 3:
        matches.append(PatternMatch(id="P5", confidence="medium", ...))

    # 部分覆盖检测
    for m in matches:
        unavailable = [
            rid for rid in ("R1","R2","R3","R4","R5","R6","R7")
            if results.get(rid, {}).get("status") in ("insufficient_data", "not_applicable")
        ]
        if unavailable:
            m.partial_coverage = True
            m.unavailable_rules = unavailable

    return matches
```
