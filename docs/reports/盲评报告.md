## 改进建议

1. 派生指标 Claim 应绑定完整计算输入：当前期、同比基期、分母与历史窗口；不能只绑定当前期两个字段。
2. `source_excerpt` 应保存来源原文或明确标成 `derived_explanation`；不要把规则 explanation放进看似原始证据的字段，否则会形成“Claim 证明 Claim”的循环。
3. Evidence 增加 `formula`、`input_evidence_ids` 与 `calculation_version`，前端可展示“原始值 → 公式 → 派生值”的可复算链。
4. Evidence 的 `dataset_version` 必须与库内 `companies.dataset_version` 对齐；本报告已分别展示二者，若不一致不得宣称版本链完整。
